# Famous Last Words: The Funniest Epitaph

Entry for the make.fun bounty "Famous Last Words: The Funniest Epitaph".

Running `main.ts` writes one line of famous last words to `/output/entry.txt`:

> I can see the light. It says 'out of order'.

The line is a single tombstone epitaph, 44 characters, inside the 1-150 character gate.
